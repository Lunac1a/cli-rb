## 实测证据

- Python 3.12.10、uv 0.12.8 可用；依赖安装完成。
- `uv run cli-rb demo`：观察到工具请求 → 工具返回 → 模型回答。
- `uv run pytest -q`：19 项通过，覆盖直接回答、工具往返、工具错误恢复、
  路径拒绝、分段读取、配置边界及不静默回退。
- `uv run ruff check src tests`：通过。
- `uv build`：wheel 与源码包构建成功。打包范围显式限定，不包含缓存或原有 IDE 文件。
- 当前受限执行环境中 pytest 缓存目录创建出现权限警告，19 项断言均通过；
  使用 `-p no:cacheprovider` 可以禁用非必要的测试缓存。
- Docker：PATH 未找到命令，标准 Docker Desktop 可执行路径也不存在。
  这不排除机器其他位置存在安装。
- WSL：本执行环境的状态查询返回访问拒绝，不能据此判定 WSL 未安装。
- LM Studio：命令行程序存在；初次检查 localhost:1234 拒绝连接。
  用户确认尚未下载模型，随后选择 Qwen3.5 9B Q4_K_M 下载。
