# 0005：空答复的有限恢复

2026-09-24 的直接 API 诊断确认：本地 Qwen 返回 `content=""`、无工具请求、`finish_reason=stop`，总输出 97 tokens，其中 reasoning 96；没有达到 2048 输出上限。此处能定位到服务响应边界，不能据此区分模型、模板或服务解析器的底层根因。LangChain 和终端没有漏掉可见正文。

LM Studio 的 [API 更新说明](https://lmstudio.ai/docs/developer/api-changelog) 说明正文和 reasoning 可使用不同字段。程序不把 reasoning 当成最终答复，也不修改用户的模型自动优化配置。

处理：框架循环正常结束但 AI 正文为空/仅空白且无工具请求时，最多追加一次无工具模型调用，根据原始要求和已有记录补充说明。它不重新进入工具循环。补全结果含工具请求时丢弃该回复，异常或再次空白则显示已有验证证据；不重跑编辑/命令，也不回滚已有修改。保留 `final_reply_recovery` 状态用于显示和验收。

请求历史在开始时冻结，避免终端边接收边追加历史导致重复传入工具结果。补全调用没有绑定工具，不能执行新动作。它仍受现有模型请求超时/输出上限与传输层重试策略限制；一次补全不等于一个永不重试的 HTTP 请求。
