# ADR 0003：可写副本、命令验证和应用管理的补丁

状态：采用，2026-09-23。

沿用 create_agent，不添加“测试成功就结束”的硬编码条件。工具仍由模型选择。
DockerCodingBackend 复用只读后端，开放工作副本写入与临时 /tmp；原仓库、基线、日志、
导出目录不挂载。非 root、禁网、无 capabilities、只读系统盘和资源限制继续适用。

为防止工具并行导致比较和修改交错，同一后端用锁串行执行读取/写入/命令/补丁操作。
模型被要求等待有依赖的修改结果；精确旧文本和内容校验提供额外冲突检测。
命令只能在容器内的 shell 执行，不给模型宿主机 shell 能力。
默认 60 秒超时，子进程组终止后容器销毁；有副作用的工具没有自动重试。
开始操作前记 started，正常返回后记录结果，异常留下不确定记录；还没有自动恢复功能。

命令输出合并到容器临时文件，受 8 MiB 单文件写入硬限额限制。
应用保留返回输出，发给模型的超长内容截断并给出日志 ID，可用受控工具继续读取。
这是有界日志，不承诺无限输出留存；副本总磁盘写入量尚无硬配额。

应用在允许写入前创建基线，生成 unified diff 格式的 UTF-8 文本补丁。宿主机不执行
仓库脚本或 Git hooks/filters 来生成补丁。副本扫描拒绝链接、特殊文件、超限文件，
也拒绝导出已知凭据内容。路径名使用 Git C-style quoting，测试实际 git apply，
覆盖新增/删除/空文件/CRLF/无末尾换行/中文及空格文件名。
本阶段不实现二进制差异、权限位变化和子模块；重命名表现为删除与新增。

补丁是相对会话开始的工作树，包含用户原有未提交内容作为基线；不是相对 HEAD。
出口无宿主机路径参数，应用为每次导出产生独立文件名，不自动覆盖或应用。

当前默认提供标准库运行环境。CLI_RB_IMAGE 允许使用用户预先准备的可信 Python 镜像，
程序只检查本地镜像并固定 ID，不自动构建、放开任务网络或安装宿主机依赖。

真实模型验收暴露空白最终答复，CLI 以程序证据报告兜底，保留“需求是否完成”未知，
不为获得漂亮结尾而重放变更。后续保存 response/usage 元数据用于诊断，不记录隐藏推理。
